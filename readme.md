## Run project

Run the project with localhost
go run main.go

Run the project with localhost - debug
play icon run and debug on vscode

Run the project with docker
docker-compose up --build

## Configure auto-compilation with AIR
> Install AIR on Windows
go install github.com/air-verse/air@latest

Add PATH
C:\Users\TU_USUARIO\go\bin

Place first on top
%USERPROFILE%\go\bin
en las variables de sistema solamente

Verify that it was installed
air -v

Initialize AIR
air init

Finally run with
air
